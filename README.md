# סביבת ניהול התוכן של גריין דיי

מקום אחד לערוך בו כל טקסט שלקוח רואה, בלי לגעת בקוד.

---

## מה יש בפנים

| מסך | מה עורכים |
|-----|-----------|
| נוסחי הבוט | 29 הנוסחים של בוט הוואטסאפ, מילות המפתח שמפעילות אותם והעדיפות ביניהם |
| עובדות העסק | מחירים, שעות, אזור שירות, כשרות. גם העובדות הפנימיות שהבוט לא אומר ללקוח |
| תסריטי מרכזייה | נוסחי ה-IVR של 015 |
| מדריכים | מדריכי שירות לקוחות לצוות |
| היסטוריה | 30 השינויים האחרונים, מי שינה מה ומתי |

## איך זה עובד

```
סביבת הניהול  ─┐
                ├─→  Supabase (bot_replies, kb_facts, ivr_scripts, guides)
n8n / הבוט     ─┘
```

**Supabase הוא מקור האמת.** אתה עורך נוסח בדפדפן, הוא נשמר בטבלה, ו-n8n קורא אותו בשיחה הבאה. אין שלב פרסום ואין צורך לגעת בקוד.

n8n מושך את ההגדרות מ:

```
POST https://ugevcdpfksvzujsxoauz.supabase.co/functions/v1/content
{"action":"bot_config","key":"<הסיסמה>"}
```

זה מחזיר רק את מה שהבוט צריך — נוסחים פעילים, ממוינים לפי עדיפות, בלי ההערות הפנימיות.

## הבדיקה שחוסמת שמירה

נוסחי הבוט הם הטקסט היחיד שנשלח ללקוח כלשונו, ולכן הם נבדקים לפני כל שמירה. הבדיקה רצה בזמן שאתה כותב, ואם משהו נכשל **השמירה לא מתבצעת**:

- קו מפריד (`—` או `–`)
- פנייה בלשון יחיד. באתר וב-IVR פונים ברבים, וזה גם פותר את שאלת המגדר
- אימוג'י מחוץ להודעת פתיחה, או יותר מאחד
- אותיות לטיניות
- מחיר שלא מאושר בבסיס הידע
- הבטחת כסף או תאריך
- מעל 220 תווים
- הודעת הסלמה שפותחת במחמאה כמו "שאלה מצוינת"
- הסלמת תלונה בלי התנצלות

הכללים מפורטים ב-[tone-guide.md](../tone-guide.md), והם זהים לאלה שרצים ב-`sim/lint.mjs`.

## הקובץ המקומי

`automation/canned-replies.json` הוא עותק, לא מקור. הראוטר וה-lint עובדים עליו.

```bash
node automation/sim/sync.mjs check   # יש הפרש מול Supabase?
node automation/sim/sync.mjs pull    # למשוך את הגרסה העדכנית
```

**להריץ `pull` לפני כל סימולציה**, אחרת בודקים נוסחים ישנים.

## הרצה מקומית

```bash
cd automation/content-studio && python3 -m http.server 8899
```

## כתובת וסיסמה

הדף באוויר: **https://yosef123480.github.io/greenday-content/**

הסיסמה **נפרדת מזו של הטרקר** ואינה כתובה בשום קובץ בפרויקט. היא נבדקת בצד השרת מול hash בתוך ה-edge function. הדף ציבורי וכתובת ה-API גלויה בקוד המקור, ולכן הסיסמה היא ההגנה היחידה על מה שהבוט אומר ללקוחות.

להחלפה: לחשב `shasum -a 256` של הסיסמה החדשה, להחליף את `PASS_HASH` בפונקציה ולפרוס מחדש.

לסקריפט הסנכרון:

```bash
export GD_CONTENT_KEY='<הסיסמה>'
```
